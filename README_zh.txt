下界视距上限解除：ARM64 libminecraftpe.so

这是已经通过 Frida 实测生效的同一条补丁，现在直接写入 SO。
修改文件偏移/RVA：0x12C1104。
原指令：LDR S0, [X8, #0xA88]，读取 96.0f。
新指令：LDR S0, [X8, #0x800]，读取 FLT_MAX。
原始字节：00 89 4A BD
修改字节：00 01 48 BD

文件长度不变，完整逐字节比较确认仅 0x12C1105 和 0x12C1106 两个字节改变。
原文件 SHA256：5ddfb711f5fa97abfa702e9462251d5ac8c75970425e2dc78d7ad8c380ebeb39
新文件 SHA256：e49f3f20a4776c77412ff1fd3282c52bec01531793413d37234529ba3c8abead

替换方法：
1. 备份原 APK / SO。
2. 用压缩包里的 libminecraftpe.so 替换 APK 中 lib/arm64-v8a/libminecraftpe.so。
3. 重新签名并安装。若直接替换已提取的运行时 SO，则须完全结束游戏后再替换，并保留原文件的权限、属主和 SELinux 上下文。
4. 完全结束游戏后重启，无需启动 Frida，也不要再加载 v1 验证脚本（它会因原始字节不匹配而拒绝安装）。
5. 下界视距继续由游戏内的视距设置控制。多人服务器发送区块的范围仍由服务器决定。

APK 重新签名后，能否覆盖安装取决于设备的签名校验配置；不建议为覆盖安装直接卸载游戏，避免丢失本地存档。
